# 블록월드 온라인 — 업데이트 버전

## 실행 방법
1. Node.js가 설치된 컴퓨터에서 이 폴더를 엽니다.
2. 주소창에 `cmd`를 입력해 명령 프롬프트를 엽니다.
3. `npm install`을 실행합니다.
4. `npm start`를 실행합니다.
5. 브라우저에서 `http://localhost:3000`을 엽니다.

## 조작법
- 이동: W/A/S/D 또는 방향키
- 점프: Space
- 카메라 회전: 마우스 오른쪽 버튼을 누른 채 드래그
- 카메라 줌: 마우스 휠
- PvP 공격: F 또는 화면 아래 공격 버튼 (가까운 플레이어, 25 피해, 약 0.65초 쿨다운)
- 블록 건축: 색상을 선택하고 화면을 클릭
- 블록 제거: 제거 모드를 선택하고 블록 클릭
- 점프맵: 왼쪽의 점프맵 시작 버튼, 플랫폼 위를 밟으면 체크포인트 저장
- 월드 저장: 블록은 설치/제거할 때 자동 저장되며, 서버 폴더의 `world.json`에 기록됩니다.

## 참고
- 이 버전은 브라우저에서 실행하는 3D 멀티플레이 프로토타입입니다. 인터넷에 공개하려면 별도의 호스팅/포트 설정과 보안 점검이 필요합니다.
- Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.
